## Otimização de imagens

Existe um script para gerar versões WebP otimizadas das imagens do projeto em `assets/images/optimized`.

Para usá-lo:

1. Instale dependências:

```bash
npm install
```

2. Rode o otimizador:

```bash
npm run optimize-images
```

O script usa `sharp` e gera imagens otimizadas para as pastas `projects`, `technologies` e `avatar` dentro de `assets/images/optimized`.
